MCP tools

Three primitives.
No control-panel maze.

execute()

Run code once. Return the answer and throw the sandbox away.

deploy()

Turn one file into a URL. No container spec, build service, or server process.

inbox_create()

Give the agent an address. Receive OAuth callbacks and webhooks, then expire it.

The boundary is the product

Small on purpose.

rusted is JavaScript, fetch, and a return value. It has no shell to escape, no filesystem to inspect, and no runaway loop the runtime cannot stop.

Need Python, pip, or a whole OS? Use a microVM. Need to call an API, reshape JSON, publish a webhook, or make a one-off tool? That is this.

Install / one binary

Run locally. Point at rusted.sh when you are ready.
