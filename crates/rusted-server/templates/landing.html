Why not just give it a shell

Because you would have to trust it. A model-written script is one prompt injection from hostile, and the usual answer — boot a container — costs 150ms or more before a line runs. rusted starts a fresh sandbox per call in about a millisecond, and the limits are the runtime, not a policy layer: the interrupt cannot be caught, the heap is capped, and there is no filesystem to reach.

It runs JavaScript and nothing else. If your agent needs Python and pip, you want a microVM. If it needs to call an API, reshape some JSON, or stand up a webhook — that is this.
